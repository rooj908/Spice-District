# 🍽️ Spice District - Restaurant Management & Online Food Ordering Website

**Spice District** is a modern and responsive restaurant website designed to provide customers with a smooth and user-friendly food ordering experience. Customers can explore the food menu, customize food items, add products to their cart, apply coupons, and place orders.

## 📌 Project Overview

This project demonstrates a restaurant ordering system built using modern web technologies and Object-Oriented Programming (OOP) concepts.

The website provides an interactive interface with food categories, product details, cart management, checkout, and order confirmation.

## ✨ Features

- Responsive and modern restaurant website design
- Attractive homepage and hero section
- Food menu with images and categories
- Food details and customization
- Add to Cart and Remove from Cart
- Update item quantities
- Cart total calculation
- Coupon and discount functionality
- Customer information form
- Checkout process
- Multiple payment method options
- Order confirmation
- Order receipt
- Cart data persistence using Local Storage
- Toast notifications

## 🧩 Object-Oriented Programming Concepts

This project demonstrates the following OOP concepts:

- **Encapsulation:** Managing data and methods inside classes.
- **Inheritance:** Reusing properties and methods through parent and child classes.
- **Polymorphism:** Implementing different behaviors through specialized classes.
- **Abstraction:** Organizing essential functionality through interfaces and abstract classes.

### Main OOP Classes

- FoodItem
- DesiSpecialtyFoodItem
- BeverageFoodItem
- Cart
- Customer
- BaseOrder
- RestaurantOrder
- PaymentMethod
- CashOnDelivery
- JazzCashPayment
- CardPayment

### Interfaces

- ITrackable

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/rooj908/Spice-District.git
```

**2. Navigate to the project folder**

```bash
cd Spice-District
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Build for production**

```bash
npm run build
```
